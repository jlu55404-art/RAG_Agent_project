================================================================================
                        EduRAG智慧问答系统 API文档
================================================================================

一、基础信息
--------------------------------------------------------------------------------
• 基础 URL : http://127.0.0.1:8000
• 框架     : FastAPI
• CORS     : 允许所有来源


二、接口列表
--------------------------------------------------------------------------------

1. 创建新会话
--------------------------------------------------------------------------------
• 路径     : POST /api/create_session
• 描述     : 创建一个新的对话会话
• 请求体   : 无
• 响应示例 :
  {
    "session_id": "uuid-string"
  }


2. 获取历史消息
--------------------------------------------------------------------------------
• 路径     : GET /api/history/{session_id}
• 描述     : 获取指定会话的历史对话记录
• 路径参数 :
  - session_id (必填): 会话ID
• 响应示例 :
  {
    "session_id": "string",
    "history": [
      {
        "question": "string",
        "answer": "string"
      }
    ]
  }


3. 清除历史消息
--------------------------------------------------------------------------------
• 路径     : DELETE /api/history/{session_id}
• 描述     : 清除指定会话的历史记录
• 路径参数 :
  - session_id (必填): 会话ID
• 响应示例 :
  {
    "status": "success",
    "message": "历史记录已清除"
  }


4. 非流式查询
--------------------------------------------------------------------------------
• 路径     : POST /api/query
• 描述     : 提交问题查询，只调用bm25搜索，返回同步响应或提示使用流式接口
• 请求体   :
  {
    "query": "string",           // [必需] 用户问题
    "source_filter": "string",   // [可选] 学科类别过滤
    "session_id": "string"       // [可选] 会话ID
  }
• 响应示例 :
  {
    "answer": "string",          // 答案内容或提示信息
    "is_streaming": false,       // 是否需要流式响应
    "session_id": "string",      // 当前会话ID
    "processing_time": 0.123     // 处理耗时（秒）
  }
• 逻辑说明 :
  如果返回的 `is_streaming` 为 `true`，前端需要使用 WebSocket 接口获取完整答案。


5. 流式查询（WebSocket）
--------------------------------------------------------------------------------
• 路径     : ws://127.0.0.1:8000/api/stream
• 描述     : 通过 WebSocket 接收流式响应，提交问题查询，调用完整RAG流程
• 发送消息 :
  {
    "query": "string",           // 用户问题
    "source_filter": "string",   // 可选，学科类别过滤
    "session_id": "string"       // 会话ID
  }
• 接收消息类型 :
  1. start : {"type": "start", "session_id": "string"}
     说明: 流式响应开始
  2. token : {"type": "token", "token": "string", "session_id": "string"}
     说明: 答案片段
  3. end   :
      {
        "type": "end",           // 响应结束
        "session_id": "string",  // 会话ID
        "is_complete": true,     // 是否完成
        "processing_time": 0.123 // 查询耗时
      }
     说明: 响应结束
  4. error : {"type": "error", "error": "string"}
     说明: 错误信息


6. 获取学科类别
--------------------------------------------------------------------------------
• 路径     : GET /api/sources
• 描述     : 获取可用的学科类别列表
• 响应示例 :
  {
    "sources": ["数学", "物理", "化学", "..."]
  }


7. 健康检查
--------------------------------------------------------------------------------
• 路径     : GET /health
• 描述     : 检查 Web 服务是否存活
• 响应示例 :
  {
    "status": "healthy"
  }
